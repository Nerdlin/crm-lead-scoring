# CRM AI Lead & Contact Scoring — Аналитическая часть (РК-1)

Репозиторий аналитической части дипломного проекта к первому рубежному контролю по дисциплине **«Аналитика больших данных в бизнесе» (ABDB)**.

**Тема проекта:**  
> «Разработка централизованной CRM-системы с интеграцией технологий искусственного интеллекта для систематизации данных и автоматизации внутренних процессов (на примере EY Academy of Business)»

---

## 🎯 Аналитическая задача
Интеллектуальный скоринг входящих заявок и телефонных контактов (**Lead & Contact Scoring**) для приоритизации работы менеджеров по продажам программ профессионального обучения EY Academy (ACCA, CPA, DipIFR, открытые тренинги).  
Модель на основе признаков, известных **строго до первого звонка менеджера**, ранжирует очередь обращений по вероятности оплаты обучения $P(\text{оплата} \mid x, t_0)$ и распределяет клиентов по SLA:
* **Горячая очередь:** звонок в течение $\le 15$ минут;
* **Стандартная очередь:** контакт в течение 24 часов или омниканальная рассылка.

## 🚀 Воспроизведение одной командой

### 1. Установка окружения
```bash
python -m venv .venv
# Для Windows:
.\.venv\Scripts\activate
# Для Linux/macOS:
source .venv/bin/activate

pip install -r requirements.txt
```

### 2. Запуск всего аналитического цикла
```bash
python src/run_all.py
```
Скрипт автоматически:
1. Загрузит верифицированный датасет-аналог Bank Marketing (UCI / зеркало Kaggle) и проверит его SHA-256;
2. Проведёт аудит синтетического кандидата Maven CRM, доказав отсутствие в нём предиктивного сигнала;
3. Сформирует слои Data Lake (`raw` $\to$ `processed` $\to$ `features`);
4. Рассчитает чек-лист качества по 8 параметрам;
5. Выполнит разведочный анализ (EDA), выявив утечки целевой переменной через `duration` и скрытые пропуски;
6. Обучит baseline-модели на честном Out-of-Time тесте (хронологическое разбиение 80/20);
7. Выполнит замеры производительности на масштабах $\times 1$ и $\times 25$ ($> 1$ млн строк);
8. Отрендерит процессную схему BPMN (to-be) и схему потоков данных Dataflow;
9. Скомпилирует и сохранит итоговый Word-документ `reports/report_RK1.docx`.

## 📊 Ключевые результаты

| Модель | ROC-AUC | PR-AUC | Precision@20% | Recall@20% | Lift@20% | Эффект 20%, млн ₸ |
| :--- | :---: | :---: | :---: | :---: | :---: | :---: |
| **B0: Константа (случайный порядок)** | 0.500 | 0.308 | 31.2% | 20.2% | 1.01x | 68.86 |
| **B1: Правило «история × канал»** | 0.658 | 0.460 | 56.9% | 36.9% | 1.85x | 132.31 |
| **B2: Логистическая регрессия (Baseline)** | **0.699** | **0.544** | **59.9%** | **38.9%** | **1.94x** | **139.81** |
| **B2+: + Месяц и макроконтекст** | 0.747 | 0.536 | 59.6% | 38.7% | 1.94x | 139.21 |
| *L: + Длительность звонка (утечка)* | *0.823* | *0.604* | *63.2%* | *41.0%* | *2.05x* | *148.06* |

* **Lift@20% = 1.94x:** в верхних 20% очереди скоринга концентрируется 38.9% всех покупателей образовательных программ.
* **Экономический эффект:** применение модели B2 приоритизации обеспечивает дополнительно **+70.95 млн ₸ маржи** на тестовом сегменте по сравнению со случайным порядком обзвона.
* **Выявление Data Leakage:** длительность звонка (`duration`) искусственно завышает ROC-AUC до 0.823, но в момент поступления заявки неизвестна и строго изолирована из промышленного признакового пространства.
